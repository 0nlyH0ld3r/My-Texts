# Análise de Algoritmos
- Queremos mensurar consumo de recursos:

    - Tempo gasto de processamento

    - Memória utilizada

    - Mensagens enviadas na rede (em computação distribuída)

- Esta medida do consumo de recursos determina a COMPLEXIDADE de um algoritmo

## Complexidade

A complexidade deve ser mensurada de forma a expressar o uso de recursos sem depender do computador,
da linguagem de programação ou de um computador específico, mas do algoritmo

- Complexidade temporal:    Tempo gasto de processamento

    - Segundos


- Complexidade espacial:    Relacionada à memória utilizada

    - Bytes ocupados na memória

### Medindo o tempo

- Cada instrução é executada em um número fixo de ciclos de máquina

- Máquinas modernas têm pepeline (no exemplo, 4 ciclos para todas as instruções. Média de 2 para cada)

- Não é tão possível medir dessa forma.
